# neagenia-site

Ιστοσελίδα Νέα Γενιά «Πράξις» Ολυμπιακού Χωριού — [neageniaolv.org](https://neageniaolv.org)

## Πώς ενημερώνεται

**Το περιεχόμενο** (άρθρα, ανακοινώσεις, δράσεις, φωτογραφίες, χορηγοί) γράφεται
από το πάνελ διαχείρισης της ίδιας της σελίδας και δημοσιεύεται αμέσως. Δεν
απαιτείται τίποτα από εδώ.

**Ο κώδικας** (σελίδες, σχεδιασμός, λειτουργίες) ζει σε αυτό το repository και
δημοσιεύεται μέσω GitHub Pages με κάθε commit στο `main`.

## Πνευματικά δικαιώματα

Τα πνευματικά δικαιώματα του κώδικα και του σχεδιασμού ανήκουν στον
**Δημήτρη Γαλλή (DG Creative Studio)**.

Παραχωρείται στη «Νέα Γενιά Πράξις» Ολυμπιακού Χωριού δωρεάν και αμετάκλητη
άδεια χρήσης, συντήρησης και τροποποίησης για τις ανάγκες της ομάδας, με
δικαίωμα ανάθεσης της συντήρησης σε τρίτο συνεργάτη της επιλογής της.

Απαγορεύεται η αντιγραφή, αναδημοσίευση ή επαναχρησιμοποίηση του κώδικα από
τρίτους για οποιονδήποτε άλλο σκοπό.
